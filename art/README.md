# Battle-AQ art pipeline

Every model, texture and lightmap in `web/public/assets/` is **generated by
Blender Python scripts** in `art/blender/` — nothing is hand-edited in a
`.blend`. The scripts are the source; the files in `assets/` are build output
(committed so the game runs without Blender).

```bash
art/build.sh                # rebuild everything (Blender 4.2+, headless is fine)
art/build.sh maps           # or one stage: textures | maps | characters | weapons
```

| Script | Output | What it does |
|---|---|---|
| `build_textures.py` | `assets/tex/<id>.jpg`, `<id>_n.jpg` | 17 tileable 512 px surfaces (sandstone, plaster, cobbles, planks, crates, painted metal, mossy stone, hedge, water, shutters, doors…) from procedural Cycles node graphs. Torus-mapped 4D noise makes them tile seamlessly. Albedo + normal map. |
| `build_maps.py` | `assets/maps/<id>.glb`, `<id>_lm.jpg` | Builds each map from the **same collider list the server uses** (`web/tools/export-maps.mjs`), trims faces hidden inside other boxes, adds flush decals (windows, doors), coping caps and an unreachable skyline, then bakes sun + sky + bounce light with Cycles into a 2048 px lightmap (second UV set, denoised with OIDN). |
| (props) | in `<id>.glb` | Oil drums, sandbag walls, pallet stacks, planters and stone arches, modelled over the collision footprints in `web/shared/props-data.js` (generated and route-checked by `web/tools/place-props.mjs`). |
| `build_characters.py` | `assets/models/skin_<id>.glb` (8 skins) + `hostage.glb` | four skins per team (T: phoenix / leet / arctic / guerilla, CT: seal / gsg9 / sas / gign), ~5k-triangle soldiers rigidly skinned to an 11-bone rig; cloth / camo / webbing / face materials baked into one 1024 px atlas. Clips: idle, walk, run, crouch_idle, crouch_walk, jump, death. |
| `build_skin_portraits.py` | `assets/ui/skins/<id>.jpg` | appearance-menu portraits rendered from the skin models. |
| `build_weapons.py` | `assets/models/weapons.glb` | Ten guns, the knife and the C4, plus articulated gloved hands per team (separate phalanges curled round the grip, index on the trigger). Each gun has `<id>_muzzle`, `<id>_grip` and `<id>_lhand` empties the hands attach to. Albedo + normal (Cycles Bevel) + roughness bakes; edge wear from Pointiness. |

Review helpers (not part of the build): `preview.py` renders GLBs,
`contact_sheet.py` tiles textures 2×2 to show seams.

## How it renders (and why it is cheap)

The level is drawn the way GoldSrc drew BSPs: unlit materials, one tiling
texture times one baked lightmap. There are no real-time lights or shadow maps
on the world, so it runs on old integrated GPUs. Players and weapons are the
only lit objects. They take their brightness from the lightmap under their
feet, so a player in shadow is darker, as in CS 1.6.

## Conventions

- Units are game units (1 u ≈ 1 inch). Blender is Z-up, facing +Y; the glTF
  exporter converts to three.js Y-up, facing −Z (the game's yaw-0 forward).
- Map materials are named after texture ids (`dust_sandstone`, …). The client
  binds `assets/tex/<name>.jpg` by name, so textures are shared across maps.
- Lightmaps store `(irradiance / 4) ^ (1/2.2)`. The client decodes them as sRGB
  with `lightMapIntensity = 4π` (`LM_SCALE` in `build_maps.py` and `world.js`
  must match).
- Map look (texture per palette material, sun direction and colour) lives in
  `web/shared/themes.js`, which both the bake and the client read.
